Instagramアカウントの作成

初回のみ

営業専用のアカウントを新しく作ります。個人アカウントは使いません。

Aアイコンを設定する

アイコンは全員共通で、下のロゴ画像を使います。スマホなら画像を長押し→「写真に保存」、パソコンなら「画像を開く」から右クリックで保存して、Instagramのプロフィール写真に設定してください。

画像を開く（保存用）
黒背景に白の「M」ロゴ。これ以外のアイコンは使用不可。

Bアカウント名を予約する（早い者勝ち）

名前は下の候補から選びます。他のスタッフと同じ名前は使えないため、このページ上で予約する仕組みになっています。予約すると、その名前は他の人の画面で選べなくなります。

  1. まず自分の本名を入力する
  2. 空いている名前をタップして選ぶ
  3. 「この名前で確定する」を押す
  4. 確定した名前を、Instagramの「名前」欄にそのまま入力する
候補を読み込んでいます…
間違えて確定した場合は、自分の本名を入れたまま別の名前を選び直して確定すれば、前の予約は自動で解放されます。うまくいかない時は中村へ連絡してください。

Cプロフィール文（概要）を設定する

「プロフィールを編集」→自己紹介の欄に、下の文をそのまま貼り付けます。

SNS・LINE・HPで集客導線を仕組み化
編集代行｜HP制作｜公式LINE構築・運用
AI導入支援・コンサル
ご相談・ご依頼はDMから📩

Dリンク欄にURLを設定する

「プロフィールを編集」→リンク→「外部リンクを追加」に、下のURLを貼り付けます。

https://mono-create-group.github.io/lp/mono-create/
プロフィール完成イメージ。A〜Dがそのまま上の作業に対応しています。

コピーしたら自分のメモアプリに貼り付けて保存してください。毎日ここから貼るのではなく、メモアプリから貼るのが基本動作です。

    
完成イメージについて: 送付相手のジャンル（美容室・整体など）の完成イメージURLがある場合だけ添付します。担当ジャンルと完成イメージは中村から都度共有されるので、共有されたら上の欄に貼って作り直してください。

営業送付（社内アプリ「営業リスト」の使い方）
毎日

  
送り先は社内アプリの営業リストで管理しています。「開く→絞り込む→送る→その場で記録」の4動作だけです。

  1. 下のURLを開き、登録済みのGoogleアカウントでサインインする（初回のみ。未登録の場合は中村に連絡すると追加されます）
    2. 
      
  2. 下部メニューの「営業」→「営業リスト」タブを開く
    3. 
    

    

      
https://mono-create-group.github.io/editflow-team/

      
    

    
スマホはブラウザで開いて「ホーム画面に追加」しておくと、アプリのように毎日開けます。

  


  

    
B今日の送信先を絞り込む

    
画面上部の絞り込みボタンを、毎回この組み合わせにします。

    
    
      
  1. 事業タブ: HP制作（AI事業担当の人は指示された事業タブ）
    2. 
      
  2. ジャンル: 中村から指定されたジャンルを選ぶ（担当ジャンルはその都度、中村から共有されます。指定がない日は絞り込みなしでOK）
    3. 
      
  3. ステータス: 未接触
    4. 
      
  4. 連絡先: IGあり（Instagramが登録されている店だけに絞る）
    5. 
      
  5. 担当: 未割当（他の人が着手していない店だけに絞る）
    6. 
      
  6. 「被りなし」をON（他の事業で最近接触した店を除外する）
    7. 
    

    
この状態で上から順に送っていきます。リストの店を探したり選んだりする判断は不要です。

  


  

    
CDMを送る

    
    
      
  1. 店舗カードのInstagramリンクをタップしてプロフィールを開く
    2. 
      
  2. 投稿を1〜2個見て、実在の営業中の店か確認する（閉店・更新停止ならメモに「休止」と書いて次へ）

送信した直後に、同じ店舗カードで次の3つをタップします。

    
    
      
  1. 担当: 自分の名前（ボタンに自分の名前がない場合は中村に連絡すると追加されます）
    2. 
      
  2. 営業方法: InstagramDM
    3. 
      
  3. ステータス: 「未接触」→「DM済み」に変更
    4. 
    

    
この3タップで「今日・誰が・何件送ったか」が自動で集計されます。記録がない送信は件数に入りません。

    

      
      
店舗カードの記録イメージ。送信直後にこの3か所をタップします。

    

  


  

    
E返信が来たら

    
    
      
  • 返信にはその日のうちに返す（鮮度が命）
    • 
      
  • 興味あり（「見ました」「気になります」等）→ すぐ中村へ共有。商談以降は中村が引き継ぎます

    •

厳守
毎日のルール

  

    
1日20通までInstagramの凍結（アカウント停止）を避けるための安全上限。新規アカウントの最初の1週間は1日10通までに抑える。

    
追撃は1回だけ3日後のフォロー1通のみ。それ以上のしつこい送信は禁止。

    
記録はその場で送信のたびに担当・営業方法・ステータスをタップ。まとめて後で、は禁止。

    
価格は言い切る「49,800円のみ」。値引きの相談をされたら自分で判断せず中村へ。

    
文面を勝手に変えないテンプレートの文章はそのまま使う。変えたい案があれば中村へ提案。

    
誇大表現の禁止「絶対に売上が上がります」等は言わない。無料デモと実物で伝える。
